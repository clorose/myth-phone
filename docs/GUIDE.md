# MythPhone 사용 설명서

GM과 플레이어가 실제로 쓰는 방법. 기능 명세는 `FEATURES.md`, 데이터를 채우는 형식은 이 문서의 스키마 절 참조.

## 기본 조작

- 우측 하단 폰 버튼으로 열고 닫기. ESC·배경 클릭·홈 버튼으로 닫기/홈 이동.
- 홈 아이콘의 빨간 배지 = 안 읽은 버블톡 수.
- 모듈 설정 → "디버그 로그"를 켜면 소켓 송수신·읽음 처리가 토스트로 표시됨 (문제 확인용, 클라이언트별).

## GM: 대화 걸기

- **캐릭터 개인톡**: 버블톡 우상단 가면 버튼 → 발신 캐릭터(플레이어 소유가 아닌 Actor만 표시)·대상 플레이어 선택 → 대화 열기. 플레이어에겐 캐릭터 이름으로 보임.
- **전화**: 전화 앱 → `캐릭터로 전화 걸기` → 캐릭터·대상·장면 선택 → 발신. 대상 플레이어만 벨소리·수신 화면. 응답/거절 결과가 GM에게 알림으로 옴.
- **단체톡**: 버블톡 단체 대화 탭 우상단 버튼 → 방 이름·참여자 선택 (플레이어도 만들 수 있음).
- **이미지 보내기**: 채팅방 + 버튼 → 파일 선택. 입력창에 텍스트가 있으면 캡션으로 같이 감. (파일 탐색 권한 필요)

## GM: 연출 데이터 채우기

세 파일 모두 모듈 폴더의 `data/` 안. 수정 후 브라우저 새로고침(F5)으로 반영.

### 메시지 앱 — `data/messages.json`

```json
{
  "conversations": [{
    "id": "msg-jia",              // 고유 ID
    "name": "지아", "initial": "J",
    "preview": "목록에 보일 마지막 줄",
    "listTime": "오후 8:46",       // 표시용 문자열
    "unread": 1,                   // 목록 배지 (연출용)
    "status": "접속 중",
    "timelineTime": "오늘 오후 8:44",
    "messages": [
      { "direction": "received", "text": "본문", "time": "오후 8:44" },
      { "direction": "sent", "text": "답장", "image": "worlds/월드명/img/단서.jpg" }
    ]
  }]
}
```

### 이메일 앱 — `data/emails.json`

```json
{
  "emails": [{
    "id": "email-001",
    "from": { "name": "보낸이", "address": "who@where" },
    "subject": "제목", "preview": "목록 미리보기",
    "time": "오전 9:12", "unread": true,
    "body": "본문. \\n\\n 로 문단 구분.",
    "image": "worlds/월드명/img/첨부.jpg"   // 선택
  }]
}
```

### 전화 장면 — `data/call-scenes.json`

```json
{
  "scenes": [{
    "id": "scene-id", "name": "발신 화면에 보일 이름",
    "caller": { "name": "기본 발신자", "initial": "M", "number": "010-..." },
    "beats": [
      { "delay": 500, "type": "dialogue", "speaker": "caller", "text": "대사" },
      { "delay": 8000, "type": "stage", "text": "[지문]", "effect": "knock" },
      { "delay": 12000, "type": "end", "effect": "disconnect" }
    ]
  }]
}
```

- `delay`: 응답 시점부터 ms. `effect`: knock / impact / steps / disconnect.
- 발신 시 캐릭터를 고르면 장면의 caller 표시를 그 캐릭터가 덮어씀.

## GM: 브라우저 사이트

1. HTML 파일을 Foundry `Data/` 아래에 둔다. 권장: `Data/worlds/월드명/sites/뉴스.html`
2. 폰 브라우저 → + 버튼 → 이름·주소(`worlds/월드명/sites/뉴스.html`) 등록
3. 목록은 전원 공유, 페이지는 iframe으로 격리 표시. 삭제는 휴지통 아이콘.

## GM: 연락처

- 연락처 앱 + 버튼 → 캐릭터·전화번호 등록 (번호는 Actor 플래그에 저장)
- 연필 버튼으로 수정·삭제. 플레이어는 등록된 캐릭터에게 먼저 말을 걸 수 있음 (답장은 GM에게).

## 로그 내보내기 (설정 앱)

- **GM**: `전체 통합 로그` = 기본 채팅 + 캐릭터 방을 시간순 HTML(방별 배경색·범례)로. `단체톡 포함` 체크 시 단체방도. **유저끼리의 개인톡은 GM에게 절대 안 나옴.**
- **모두**: 자기가 참여한 방을 방 단위 txt로 저장. 유저 간 개인톡은 이 방법으로 당사자가 직접 뽑아 제공할 때만 공개됨.

## 플레이어 안내

- 버블톡 친구 탭 = 실제 접속자(캐릭터 이름). 눌러서 1:1 대화.
- 안 읽은 메시지는 배지·알림음으로 표시되고, 방을 열면 지워짐. 보낸 메시지 옆 숫자는 상대가 읽으면 사라짐.
- 대화는 저장되므로 재접속해도 남아 있음.
