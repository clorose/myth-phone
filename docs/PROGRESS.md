### 2026-07-25 — 실제 기능 전환

- GitHub 저장소 연결 (`clorose/myth-phone`), 작업 단위 커밋 시작
- 버블톡 UI 디테일: 말풍선 꼬리, 연속 메시지 묶음, 읽음 표시, 입력 중, 배경 패턴, 모자이크 아바타, 탭 배지
- 공통 계층 분리: `utils.js`(이스케이프·시간), `store.js`(데이터·pub/sub), `socket.js`(game.socket 라우팅)
- 전화 소켓 발신: GM이 캐릭터·대상·장면 선택 → 대상 플레이어에게만 수신
- 버블톡 실채팅: 1:1 → 캐릭터(NPC) 명의 개인톡 → 단체톡 (`ChatMessage` 귓속말 기반)
- 안읽음·알림(배지, 읽음 숫자 실시간 갱신, 알림음), 통화 기록 영구 저장
- 연락처를 실제 유저·Actor와 연결
- 로그 내보내기와 프라이버시 정책 확정 (유저 간 개인톡은 본인 공개 없이는 노출 불가)
- 디버그 로그 토글

### 2026-07-26 — 정리와 확장

- 표시 이름을 계정 닉네임 대신 배정 캐릭터 이름으로 통일, UI 문구에서 "NPC" 지칭 제거

- 통합 로그를 색상 구분 HTML로 전환 (방별 배경색 + 범례, 단체톡 포함 옵션)
- 버블톡 더미 데이터 제거 — 버블톡은 전부 실채팅
- 브라우저 앱 (GM 등록 사이트 + 주소창 + iframe 뷰어)
- 이메일 앱 (받은편지함·상세, 연출용 데이터)
- 테스트 체크리스트(`TESTING.md`) 작성

### 2026-07-27 — GM 연출 편집기

- 메시지·이메일 정본을 번들 JSON에서 월드 설정(`myth-phone.messages`/`emails`)으로 전환, 최초 1회 시드(`seeded` 플래그)
- GM 전용 `연출 편집` 앱 (홈 그리드, GM만 표시) — 메시지/이메일 탭, 폰 안 목록→상세
- 메시지: 말풍선 쌓기(받음/보냄 토글, 인라인 편집·삭제·방향 전환) + 메타 필드
- 이메일: 보낸사람·제목·시각·본문 폼 편집
- JSON 가져오기/내보내기, 원격 변경 시 열린 목록 화면 자동 갱신(`updateSetting`)

### 2026-07-27 — 설정 알림 토글

- 설정 앱의 알림·메시지 소리·미리보기 토글을 실제 동작에 연결 (클라이언트 설정 `notifEnabled`/`notifSound`/`notifPreview`)
- 알림 OFF → 새 메시지 토스트 없음, 소리 OFF → 알림음 없음, 미리보기 OFF → 내용 대신 "새 메시지"만

### 2026-07-28 — GM 연출 편집기 폰에서 분리

- 연출 편집기를 폰 안 앱에서 **독립 ApplicationV2 창**(`apps/gm-editor-window.js`)으로 이전. 좌측 Scene Controls 버튼(GM 전용)에서 연다. 폴백 API `game.modules.get("myth-phone").api.openGmEditor()`
- 렌더 로직(`gmEditorMethods`)·데이터 계층 그대로 재사용, 폰 홈 그리드에서 GM 버튼 제거
- 목적: 저작 공간 확보 → 다음 단계 "메시지/이메일 수신 대상 지정"의 토대
- ⚠️ Foundry 스모크 테스트 미완: ApplicationV2 렌더 계약·Scene Controls v14 버튼 표시 실제 확인 필요

### 2026-07-28 — 버그 수정·로깅 정리

- Scene Controls GM툴 툴의 deprecated `onClick` 제거(`onChange`만 유지) — v13 경고 해소
- GM 편집기 목록 삭제 버그 수정: 클릭이 버튼에 잡혀 편집으로 새던 것을 **클릭 좌표 판별**로 고침. 삭제 확인창(`DialogV2.confirm`) 추가
- 로깅을 `scripts/log.js` 단일 제어점으로 일원화(`debug`/`warn`/`error`, raw `console.*` 제거). `debug`는 `debugLog` 게이트로 기본 꺼짐 → 배포 시 자동 조용

### 2026-07-28 — 연출 발송 (수신 대상 지정)

- 방식 확정: **결합형** — 편집기에서 미리 작성, 발송 버튼으로 그 순간 대상을 골라 공개 (상세는 `DECISIONS.md`)
- 항목별 `sentTo` 배열: 없음=구 데이터 전체 공개, `[]`=미발송(새 항목 기본), `[ids]`=그 사용자만. 플레이어 폰은 `PhoneStore.visibleList`로 필터, GM은 전부 봄
- 편집기 목록에 발송 버튼(종이비행기·인원 배지) + 대상 체크박스 다이얼로그(회수 겸용)
- 발송 순간 신규 수신자에게만 소켓 `staged-send` 알림(토스트+알림음, 알림 설정 존중). 데이터 동기화는 기존 `updateSetting` 경로
- ⚠️ Foundry 스모크 테스트 미완: `TESTING.md`의 "연출 발송" 절 확인 필요
- 발송 다이얼로그 전체 선택 토글, X 닫기=취소 확정(`rejectClose` 명시), 연출 말풍선 `esc()` 누락 수정

### 2026-07-28 — 버블톡 아바타 초상화

- 친구 목록·채팅방 목록·대화 헤더·받은 말풍선 아바타를 **배정 캐릭터 초상화**(`actor.img`)로 표시. NPC 방은 NPC Actor 초상화
- 초상화 없음·기본 아이콘(mystery-man)·미배정은 글자 동그라미 폴백. 초상화는 렌더 시점 계산이라 변경 즉시 반영
- 단체방 모자이크는 글자 유지(초상화 모자이크는 추후)
- ⚠️ Foundry 스모크 테스트 미완: `TESTING.md`의 "아바타 초상화" 절 확인 필요

### 2026-07-28 — 실기 버그 3건 수정 (스크린샷 제보)

- GM툴을 별도 컨트롤 그룹 → **토큰 컨트롤 안 버튼 툴**로 이전: 같은 아이콘 2개 표시(그룹+툴), X 닫으면 재오픈 불가(activeTool 버튼 재클릭 무시) 둘 다 해소. 창 인스턴스도 닫힌 것 재활용 대신 새로 생성
- 채팅방 목록·대화 헤더의 **접속 표시(초록 점·상태문구)를 렌더 시점 계산**으로 — 방 생성 때 저장한 값이 이후 로그인을 못 따라가던 버그(친구 탭과 불일치)
- 이메일 상세의 전역 뒤로가기 겹침(`«`) — `:has(.phone-email-header)` 숨김 규칙 추가 (UI_CONVENTIONS 재발 기록)

## 앞으로 할 것

1. 캐릭터 연락처 노출 범위 — 아는 캐릭터만 표시
2. 단체톡 초대·나가기
3. 브라우저 페이지 템플릿 (제작 보조 도구)
4. **폰 스킨 시스템** — 디자인을 통째로 갈아끼울 수 있게: 피처폰, 갤럭시(One UI), MythPhone(현행 아이폰풍) 등
   - **선행 작업**: 디자인 시스템 분리 — 현재 색·모양이 토큰(`--phone-*`)에 다 안 모여 있음. 하드코딩 색(아바타 그라디언트, 온라인 점 등)과 JS 안 팔레트(store.js `groupPalette`)를 토큰으로 끌어올려야 스킨이 절반짜리가 안 됨
   - 갤럭시·피처폰은 색만이 아니라 구조(상태바, 하단 내비 바, 아이콘 모양, 피처폰은 키패드·비터치 UI)까지 달라서 CSS 테마 이상의 작업

## 논의됐지만 결정 대기

- 버블톡 입력 중 표시 — 렌더러·CSS만 있고 실제 타이핑 소켓 이벤트 미구현 (더미 제거 후 표시될 일 없음)
- 방 알림 끄기 — 목록의 🔕·회색 배지 표시 코드만 있고 끄는 기능(토글·플래그·알림 억제) 없음
- 채팅방 헤더 통화 버튼 — 장식 상태. 유저 간 통화는 기획 범위 밖이라 유지/제거 결정 필요
- 녹음기/음성 메모 앱 (오디오 단서 재생)
- Foundry 사이드바에서 폰 대화 구분 — Custom Chat Tabs 모듈 도입 검토
- 대화 공유 기능 (참여자가 방 내용을 전체 채팅에 공개)

## 보류 (FEATURES.md에 결정 기록됨)

- 카메라 앱 — 촬영 대상과 목적이 정해지기 전까지 개발하지 않음
- 독립 사진 갤러리 — 문맥 없는 이미지 모음은 만들지 않음, 증거 보관함 형태만 추후 검토
- 고정된 대화(핀) — 도입 시 사용자별 클라이언트 설정으로
