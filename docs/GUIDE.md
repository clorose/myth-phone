# MythPhone 사용 설명서

GM과 플레이어가 실제로 사용하는 방법을 설명한다. 목표 동작과 향후 범위는 `FEATURES.md`에서
확인한다.

## 기본 조작

- 우측 하단 폰 버튼으로 기기를 열고 닫는다.
- ESC 또는 폰 바깥 배경 클릭은 기기를 닫는다.
- 하단 홈 인디케이터와 앱의 전역 뒤로가기는 홈 화면으로 돌아간다.
- 홈 버블톡 아이콘의 빨간 배지는 읽지 않은 실제 채팅 수다.

## 버블톡

- 1:1 대화: 친구 탭에서 Foundry 사용자를 선택한다. 화면에는 배정 캐릭터 이름과 초상화를
  우선 표시한다.
- 캐릭터 명의 대화: GM은 버블톡 우상단 가면 버튼에서 Actor와 대상 플레이어를 선택한다.
  플레이어에게는 GM 계정명이 아닌 Actor 이름으로 보인다.
- 단체톡: 단체 대화 탭의 만들기 버튼에서 방 이름과 참여자를 선택한다.
- 이미지: 대화방의 `+` 버튼으로 파일을 선택한다. 입력 중인 문장이 있으면 캡션으로 함께 보낸다.
  파일 탐색 권한이 필요하다.
- 방을 열면 안읽음 배지가 사라지고, 보낸 메시지 옆 숫자는 상대가 읽으면 갱신된다.

## GM 연출 메시지·이메일

Scene Controls의 토큰 팔레트에 있는 `GM툴` 펜 버튼으로 독립 편집 창을 연다. 버튼을 사용할 수 없는
경우 콘솔이나 매크로에서 다음 API를 호출할 수 있다.

```js
game.modules.get("myth-phone").api.openGmEditor()
```

- 메시지: 받음/보냄, 월·일, 선택 시각을 지정해 말풍선을 쌓는다. 날짜·시각은 다음 입력에도
  유지된다. 기존 말풍선은 방향·시각·내용을 수정하거나 삭제할 수 있다.
- 이메일: 보낸 사람, 주소, 제목, 수신 날짜·시각, 본문을 편집한다.
- 발송: 목록의 종이비행기 버튼에서 받을 플레이어를 선택한다. 새 항목은 발송 전까지 플레이어에게
  보이지 않는다. 기존 대상의 체크를 해제해 다시 적용하면 회수된다.
- 날짜: 게임 내 연·월·일을 설정한다. 폰 날짜 줄, 연출 시점 라벨, 달력이 함께 갱신된다.
- 백업: JSON 가져오기·내보내기로 현재 world 데이터를 백업하거나 이관한다.

연출 메시지·이메일의 영구 정본은 world 설정이다. `data/messages.json`과 `data/emails.json`은
새 월드 최초 1회 시드용이므로 이후 데이터를 수정할 때 사용하지 않는다.

## GM 연출 전화

전화 앱에서 `연출 전화 걸기`를 누르고 수신 플레이어 한 명과 전화 장면 하나를 선택한다.
발신자 이름·이니셜·번호는 Actor가 아니라 전화 장면에 정의된 값을 사용한다.

- 대상 플레이어에게만 벨소리와 수신 화면이 나타난다.
- 응답하면 장면의 대사·지문·효과음을 재생한다.
- 응답·거절 결과는 GM에게 알린다.
- 플레이어가 통화 도중 직접 끊는 동작은 GM에게 보고하지 않는다.

### 전화 장면 형식

전화 장면은 `data/call-scenes.json`의 `scenes` 배열에 작성한다.

```json
{
  "scenes": [{
    "id": "scene-id",
    "name": "GM 선택 목록에 보일 장면 이름",
    "caller": {
      "name": "수신 화면에 보일 발신자",
      "initial": "M",
      "number": "010-0000-0000"
    },
    "beats": [
      { "delay": 500, "type": "dialogue", "speaker": "caller", "text": "대사" },
      { "delay": 8000, "type": "stage", "text": "[지문]", "effect": "knock" },
      { "delay": 12000, "type": "end", "effect": "disconnect" }
    ]
  }]
}
```

- `delay`: 응답 시점부터 실행까지의 밀리초
- `type`: `dialogue`, `stage`, `end`
- `effect`: `knock`, `impact`, `steps`, `disconnect`

파일을 수정한 뒤 브라우저를 새로고침해야 반영된다.

## 브라우저 사이트

1. HTML 파일을 Foundry `Data/` 아래에 둔다.
2. 폰 브라우저의 `+` 버튼에서 이름과 Data 기준 경로를 등록한다.
3. 사이트 목록은 world 설정으로 공유되고 페이지는 iframe 안에서 열린다.

예시 경로:

```text
worlds/월드명/sites/뉴스.html
```

## 연락처

- GM은 연락처 앱의 추가 버튼에서 Actor와 전화번호를 등록한다.
- GM은 등록된 Actor 연락처를 수정하거나 삭제할 수 있다.
- 플레이어는 실제 사용자 또는 등록된 Actor 연락처에서 버블톡을 시작할 수 있다.

## 로그 내보내기

- 모든 사용자는 자신이 참여한 방을 방 단위 텍스트 파일로 저장할 수 있다.
- GM의 전체 통합 로그는 기본 채팅과 캐릭터 방을 시간순 HTML로 만든다.
- 단체톡은 옵션을 켠 경우에만 통합 로그에 포함한다.
- 사용자 간 1:1 버블톡은 GM 통합 로그에 포함하지 않는다.
- 이미지 메시지는 `[사진: 경로]`로 기록한다.

## 달력

- 게임 날짜를 기준으로 월 달력을 표시한다. 게임 날짜가 없으면 현실 날짜를 사용한다.
- 날짜를 선택해 본인만 보는 개인 일정을 추가·삭제할 수 있다.
- 오늘 버튼은 기준 날짜가 속한 달로 돌아간다.
