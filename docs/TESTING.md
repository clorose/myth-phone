# MythPhone 테스트 체크리스트

현재 구현된 기능의 수동 테스트 목록. 항목을 확인하면 체크한다.

## 준비

- [ ] Foundry 재시작 후 월드 접속 (module.json 변경이 있었던 버전이면 필수)
- [ ] 클라이언트 2개: 앱 = GM, 크롬 `http://localhost:30000` = 플레이어
- [ ] 양쪽 모두 모듈 설정에서 **디버그 로그** 켜기 (소켓 발신·수신·폐기·읽음 처리가 토스트로 표시됨)
- [ ] 플레이어 유저에 캐릭터 배정 (표시 이름 테스트용)

## 전화

- [ ] GM: 전화 앱 → `캐릭터로 전화 걸기` → Actor·대상·장면 선택 후 발신
- [ ] 플레이어: 폰이 자동으로 열리고 벨소리 + 수신 화면 표시
- [ ] 다른 플레이어(대상 아님): 아무것도 안 뜸, 디버그 켜면 "폐기" 토스트
- [ ] 응답 → 장면 대본 재생, 종료 화면. GM에게 "수신" 알림
- [ ] 거절 → GM에게 "거절" 알림
- [ ] 최근 통화에 기록 남음, **새로고침 후에도 유지**
- [ ] 발신 캐릭터 목록에 플레이어 소유 캐릭터가 안 나옴

## 버블톡 1:1

- [ ] 친구 탭에 실제 유저가 **캐릭터 이름**으로 표시 (접속 점 포함)
- [ ] 메시지 전송 → 상대 화면에 실시간 표시, 말풍선 이름도 캐릭터 이름
- [ ] 새로고침 후 대화 유지
- [ ] 제3자에게는 방이 안 보임

## 아바타 초상화 (버블톡)

- [ ] 초상화 있는 캐릭터 배정 유저: 친구 목록·채팅방 목록·대화 헤더·받은 말풍선 옆에 **캐릭터 초상화** 표시
- [ ] 초상화 없는(기본 mystery-man) 캐릭터·미배정 유저: 지금처럼 글자 동그라미
- [ ] NPC 명의 대화: NPC Actor 초상화가 방 목록·헤더·말풍선에 표시
- [ ] 단체방 목록 모자이크는 글자 유지(초상화 미적용 — 알려진 범위)
- [ ] 세션 중 캐릭터 초상화 변경 후 목록 재진입 → 새 초상화 반영
- [ ] **접속 표시 실시간**: 상대가 나중에 로그인해도 채팅방 목록·대화 헤더 재진입 시 초록 점·"접속 중" 반영 (친구 탭과 일치)

## 캐릭터(NPC) 개인톡

- [ ] GM: 버블톡 우상단 가면 버튼 → 캐릭터·대상 선택 → 대화 열기
- [ ] 플레이어: 방 이름·말풍선이 캐릭터 이름으로 표시 (GM 이름 노출 없음)
- [ ] 플레이어 답장이 GM의 같은 방에 도착
- [ ] GM 방 이름은 `캐릭터 → 플레이어` 형식

## 단체톡

- [ ] 단체 대화 탭 우상단 버튼 → 방 이름·참여자 선택 → 생성
- [ ] 참여자 전원에게 방 표시, 미참여자에게는 안 보임
- [ ] 목록에 참여자 이니셜 2×2 모자이크 아바타

## 안읽음·알림

- [ ] 방 닫힌 상태에서 수신 → 알림음 + 토스트 + 홈 아이콘 배지
- [ ] 방 목록·채팅/단체 탭에 안읽음 수 표시
- [ ] 방을 열면 배지 사라짐
- [ ] 보낸 메시지 옆 숫자(1): 상대가 방을 여는 순간 **실시간으로 사라짐**

## 이미지 첨부

- [ ] GM: 채팅방 + 버튼 → 파일 탐색기에서 이미지 선택 → 전송
- [ ] 말풍선에 사진 표시, 클릭하면 크게 보기
- [ ] 입력창에 텍스트 있는 상태로 첨부하면 캡션 동시 전송
- [ ] 목록 미리보기에 "사진" 표시
- [ ] 파일 권한 없는 플레이어는 + 버튼 무반응

## 연락처

- [ ] 실제 유저가 캐릭터 이름으로 표시, 메시지 버튼 → 1:1 방 열림
- [ ] GM: 우상단 + → 캐릭터·번호 등록. 연필 버튼으로 수정·삭제
- [ ] 플레이어: 등록된 캐릭터 연락처의 메시지 버튼 → 캐릭터 대화방 열림 (답장은 GM에게)

## 로그 내보내기 (설정 앱)

- [ ] GM: 방 목록에 유저 간 개인톡이 **안 보임** (캐릭터방·단체방만)
- [ ] GM: 전체 통합 로그 → HTML 다운로드, 방마다 배경색 + 상단 범례
- [ ] 통합 로그에 유저 간 개인톡 없음, 단체톡은 체크박스 켰을 때만 포함
- [ ] 플레이어: 자기 참여 방만 목록에 표시, txt 다운로드
- [ ] 이미지 메시지는 [사진: 경로]로 표기

## 브라우저

- [ ] 독의 나침반 아이콘 → 브라우저 홈 (주소창 + 사이트 목록)
- [ ] GM: + 버튼으로 사이트 등록(이름·주소), 휴지통으로 삭제
- [ ] 등록한 사이트가 플레이어 목록에도 표시됨 (월드 설정 공유)
- [ ] 사이트 클릭 → iframe으로 페이지 표시, ‹ 버튼으로 홈 복귀
- [ ] 주소창에 `worlds/...` 경로 직접 입력해 이동
- [ ] 페이지의 CSS가 폰·Foundry UI에 영향 없음 (iframe 격리)

## 이메일

- [ ] **받은편지함 목록 행이 안 겹침** — 각 메일(보낸사람/제목/미리보기 3줄)이 온전한 높이로, 아래 행과 안 포개짐
- [ ] 메일 상세에서 뒤로가기 `‹`가 **한 개만** 보임 (전역 뒤로가기와 안 겹침)

- [ ] 홈 그리드의 이메일 아이콘 → 받은편지함 (샘플 메일 3통)
- [ ] 안읽음 점 표시, 메일 열면 사라짐 (새로고침 시 초기화되는 게 정상 — 연출용 데이터)
- [ ] 상세 보기: 제목·발신자·주소·본문 문단, ‹ 버튼으로 목록 복귀
- [ ] 검색으로 발신자·제목 필터

## GM 연출 편집기

- [ ] **시드 전환**: 이 코드로 첫 실행 시 메시지·이메일 앱에 기존 데모 데이터(지아·정비소 등, 샘플 메일 3통)가 그대로 보임 (번들 JSON → 월드 정본으로 최초 1회 이식)
- [ ] **토큰 컨트롤의 툴 팔레트에 GM만 `GM툴` 버튼**(펜 아이콘)이 보임 — 별도 그룹 아님, 아이콘 1개만. 누르면 창이 열림. **플레이어 계정엔 버튼 없음**. 폰 홈 그리드엔 더 이상 `연출 편집` 아이콘 없음
- [ ] 창을 **X로 닫은 뒤 버튼을 다시 누르면 재오픈**됨 (몇 번을 반복해도)
- [ ] 폴백: 콘솔에서 `game.modules.get("myth-phone").api.openGmEditor()` → 창 열림
- [ ] 창은 크기 조절됨(우하단 드래그). 메시지/이메일 탭 전환, 상세에서 좌상단 뒤로가기로 목록 복귀
- [ ] **메시지 편집**: 대화 선택 → 메타(이름·시각·타임라인) 수정, 뒤로가기로 저장 (안읽음 수·상태 표시 필드는 제거됨 — 안읽음은 실제 추적, 접속 상태는 버블톡 전용 개념)
- [ ] 하단 받음/보냄 토글 + 입력 → **추가**(또는 Enter)로 말풍선이 쌓임, 연속 입력 시 포커스 유지
- [ ] 말풍선 hover → 방향전환(⇄)·편집(연필)·삭제 동작. 편집은 인라인 textarea, Enter로 확정
- [ ] 편집 결과가 **메시지 앱**(플레이어 시점)에 그대로 반영 (말풍선 방향·내용·목록 미리보기)
- [ ] **이메일 편집**: 보낸사람·주소·제목·시각·본문 수정 → 저장 → 이메일 앱에 반영 (상태 select는 제거됨)
- [ ] **실제 안읽음 배지**: 대화 목록 배지 = 받은(왼쪽) 말풍선 수. 대화를 열면 0. **새로고침해도 읽음 유지**
- [ ] GM이 말풍선을 추가하면 그 수만큼 배지가 다시 뜸 (이미 읽은 부분은 다시 안 셈)
- [ ] 이메일 안읽음 점: 처음엔 표시, 열면 사라짐, 새로고침해도 읽음 유지
- [ ] **날짜 설정**: GM툴 목록 상단 날짜(월/일) 적용 → 잠금화면 **날짜 줄만** "7월 6일"로 바뀜 (시계는 현실 HH:MM 유지). **초기화** 버튼 → 현실 날짜 복귀. 월/일 빈 채 적용 → 경고
- [ ] **시점 라벨 자동 계산**: 항목 날짜 = 오늘 → 목록에 시각(시각 비었으면 "오늘") / 하루 전 → "어제" / 그 외 → "M월 D일". 대화 상단·메일 상세엔 날짜(+시각)
- [ ] GM이 날짜를 하루 넘기면 열려 있던 목록의 "오늘"이 즉시 "어제"로 바뀜 (전 클라이언트)
- [ ] 구 데이터(`at` 미설정)는 옛 자유 텍스트가 그대로 보임 — 깨지지 않음
- [ ] `+`로 새 대화/메일 생성 → 상세 편집기로 진입, 목록 휴지통으로 삭제
- [ ] 삭제 후 **새로고침해도 되살아나지 않음** (의도적 빈 상태 유지, 시드 재실행 안 함)
- [ ] **JSON 내보내기**: 현재 탭 데이터가 JSON으로 표시, 복사 버튼 동작
- [ ] **JSON 가져오기**: 배열 붙여넣기 → 덮어쓰기. 잘못된 JSON/비배열은 오류 알림
- [ ] **원격 동기화**: 플레이어가 메시지/이메일 앱을 연 상태에서 GM이 편집 → 플레이어 목록 화면 자동 갱신 (플레이어가 대화 스레드를 열어둔 중이면 안 뒤엎음)
- [ ] **GM 2명**: 한 GM이 편집기 창을 목록 화면으로 열어둔 상태에서 다른 GM이 편집 → 창 목록 자동 갱신 (상세 편집 중이면 안 뒤엎음)

## 연출 발송 (수신 대상 지정)

- [ ] **구 데이터 호환**: 이 코드로 올린 직후, 기존 항목(`sentTo` 없음)이 플레이어 폰에 이전처럼 전부 보임
- [ ] 편집기 목록 행에 **종이비행기(발송) 아이콘** 표시 — 새 항목은 회색(미발송), 발송된 항목은 개수 배지
- [ ] `+`로 새로 만든 항목은 **발송 전엔 플레이어 폰에 안 보임** (GM 폰에는 미리보기로 보임)
- [ ] 발송 클릭 → 플레이어 체크박스 다이얼로그(오프라인 표시 포함, 긴 명단은 스크롤) → 발송
- [ ] **전체 선택** 토글: 켜면 전원 체크, 끄면 전원 해제. 개별 체크를 하나 빼면 전체 선택도 해제 표시
- [ ] 대상 플레이어: **토스트 알림 + 알림음** 도착, 메시지/이메일 앱을 열면 항목 보임 (열려 있던 목록은 자동 갱신)
- [ ] 대상 아닌 플레이어: 알림 없음, 앱에도 안 보임
- [ ] 알림 설정 존중: 알림 OFF → 토스트 없음, 소리 OFF → 무음, 미리보기 OFF → 내용 대신 "새 메시지 도착"
- [ ] **회수**: 발송 다이얼로그에서 체크 해제 후 발송 → 그 플레이어 폰에서 항목 사라짐, 재알림 없음
- [ ] 이미 받은 대상을 유지한 채 재발송 → 기존 대상에게 중복 알림 없음 (신규 추가된 사람에게만 알림)
- [ ] JSON 내보내기에 `sentTo`가 포함되고, 가져오기 후에도 발송 상태 유지

## 회귀 확인 (기존 동작)

- [ ] 홈 화면, 독, 뒤로가기·홈·ESC 닫기
- [ ] 메시지 앱(연출용), 메모, 설정 화면 렌더
- [ ] 버블톡 목록이 실채팅 방만 표시 (더미 대화 없음)
- [ ] Foundry 기본 채팅·주사위 정상 동작
